## 1. 완료
- `scripts/build-data.mjs` 계열 분류 규칙 수정: (a) `baseName`이 '전공'을 통째로 떼어 `안전공학과`가 `안학과`가 되던 버그를 고치고 끝자리 전용 `stemName`·자유전공 전용 `freeName`으로 갈랐다, (b) 자유전공 가지에서 인문·사회를 자연보다 먼저 봐 `사회과학대학 자유전공학과`가 자연으로 가지 않게 했다(전자·반도체·소재·컴퓨터·모빌리티 키워드 추가), (c) SCIENCE에 `식물|작물|전지|의약`, HUMAN_OVERRIDE에 `언어정보`, MEDICAL_EXCEPT에 `바이오의약` 추가.
- 이로써 자동 교정된 곳: 안전공학과(인천대·충북대) 인문→자연, 식물의학·식물자원·특용식물·응용식물(경북·충북·경상국립·전남) 인문→자연, 인하대 이차전지융합학과 인문→자연, 한양대 ERICA 분자의약전공 인문→자연, 인하대 첨단바이오의약학과 의약→자연, 부산대 언어정보학과 자연→인문, 충북대 전자정보자율전공학부·부산대 첨단모빌리티/첨단소재자율전공 자유전공→자연, 강원대 사회과학대학 자유전공학과 자연→인문.
- **계열 오버라이드 표**(`scripts/build-data.mjs` `TRACK_OVERRIDES`, 13건). `source/results.json`에 모집단위마다 박혀 있던 `track` 10건을 이 표로 옮기고 소스에서 지웠다 — 소스는 원자료만, 우리가 내린 판단은 표 하나에. 근거를 항목마다 문자열로 적는다(docs/AUDIT.md §12).
- 조사로 새로 못박은 셋: 홍익대 예술학과 예체능→인문, 국민대 AI빅데이터융합경영학과 자연→인문, 경북대 자율미래인재학부 인문→자유전공. 고려대 학부대학은 보류(표에 넣지 않고 주석 한 줄).
- **실기 없는 예체능 표**(`PRACTICAL_EXEMPT`, 경희대 체육대학·예술디자인대학 7곳 + 세종대 창의소프트학부 2곳). 모집단위마다 `practical: true|false`가 생성물에 실린다. 화면의 `예체능 제외`는 `practical === true`만 감추고, `실기` 뱃지도 그 값을 본다. 예체능 106곳 중 실기 97곳.
- **이상치 탐지**(`scripts/anomalies.mjs` → `source/anomalies.json`). 후보는 두 갈래다 — (a) 대학×계열 2026 70%컷의 중앙값·MAD에서 크게 낮은 값, (b) 그 모집단위 `series`의 이전 연도 중앙값·MAD에서 양쪽으로 벗어난 값. **판정은 (b)로만 내린다**: 이력보다 크게 낮으면 `punk`, 값이 자기모순(백분위 범위 밖·70%컷 > 50%컷)이면 `error`, 이력이 없는 실기 예체능은 `practical`, 이력이 없는 단일값은 `unverified`(뱃지 없음), 이력대로이거나 이력보다 높으면 `normal`. 이력보다 크게 **높은** 것은 오류가 아니다 — `series`의 이전 연도 값은 2026 기준값에 대학 공식 변화량을 더해 만든 줄이라 그보다 높다는 것은 실제 상승이다. 후보 107곳(미확인 67 · 정상 20 · 오류 의심 13 · 실기 6 · 펑크 의심 1). `npm run anomalies`가 먼저 돌고 `npm run build`가 결과를 읽어 각 모집단위에 `anomaly`를 넣는다.
- 화면(FRAME §9.4): 진단 행 뱃지 `차이 → 추정 → 실기 → 이상 → 판정`(`이상`은 `punk`·`error`만), 목표 `기준 숫자`에 `이상 신호 ……… 펑크 의심 · −4.7` 한 줄, 정보 탭 `이상치` 절(앵커 `anomalies`)에 `punk`·`error`·`practical` 20곳 **행 목록**(표 아님 — 열 일곱인 표는 375px에서 `분류` 열이 밀려 나간다). 행은 제목 `광운대 경영학부 빅데이터경영전공` · 부제 값만 `2026 80.0 · 이력 84.7 · 차 −4.7`(이력이 없으면 근거 값 — 오류 의심은 `2026 61.0 · 50%컷 57.0`, 실기는 `2026 14.0 · 계열 중앙값 49.0 · 차 −35.0`) · 오른쪽 뱃지 `펑크 의심`(critical)·`오류 의심`(critical)·`실기`(neutral), 순서는 펑크 → 오류 → 실기이고 같은 분류 안은 차이 큰 순이다. 행을 누르면 진단 행과 같이 목표 탭이 열린다. 목록 끝 두 행(값만): `미확인(단일값) ……… 67곳` · `기준 ……… |값 − 중앙값| > max(3, 2.5 × MAD)`.
- `npm run build`·`npm test` 통과(테스트 96개). `tests/anomalies.test.mjs`는 합성 입력으로 탐지·분류를 검사하고, `tests/data.test.mjs`는 오버라이드·`practical`·`anomaly`가 생성물에 그대로 나왔는지 본다.
- 진단 필터 재편(FRAME §9.1): `.jr-chips` 가 줄바꿈하고(가로 스크롤·음수 마진 제거) 계열은 셀렉트로 내려갔다. 셀렉트 줄은 계열|판정|정렬 삼등분, 검색은 그 아래 한 줄(`.jr-search-row`). 375px에서 칩은 두 줄로 끝난다.
- ⓘ 를 상단바로(FRAME §9.2): `index.html` 의 `#infoButton` 하나가 탭마다 목적지를 바꾸고(성적 scale/convert · 진단·목표 verdict · 반영 basis) 정보 탭에서는 `hidden` 이다. `screenHead` 는 왼쪽 값만 남았다.
- 768px 미만 바텀시트(FRAME §9.3): 라인·대학·관심 대학 고르기를 Seed `bottom-sheet` recipe 로 연다. 스크롤 잠금·첫 행 포커스·Tab 트랩·Esc/배경/닫기/완료, 닫으면 포커스는 열었던 칩으로, 패널 스크롤 자리는 그대로(시트를 여닫을 때 패널을 다시 그리지 않는다). 768px 이상으로 넘어가면 **시트만** 닫고 `state.filterPanel` 은 그대로 둬 같은 체크 목록이 인라인으로 이어진다(칩도 `aria-expanded="true"`); 관심 대학 시트는 아코디언이 열린 채로 이어진다(`favPickerOpen`). 좁아질 때는 인라인 목록을 접는다. 성적·정보 탭의 관심 대학은 좁은 폭에서 행 하나(`관심 대학 … N곳 ›`)가 시트를 연다. 체크 아이콘은 켜진 행에만 그린다 — 꺼진 행은 `visibility: hidden` 으로 자리(22px)만 지킨다.
- 점검 이식성: `scripts/serve.mjs`(Node 내장 http)와 `scripts/measure.mjs`(공용 측정 함수)를 새로 두고, `scripts/shots.mjs` 는 `@playwright/test` 의 크로미움을 쓴다(`PW_CHROME` 이 있을 때만 `executablePath`). 윈도우에서도 그대로 돈다.
- `scripts/e2e.mjs` + `npm run e2e`: 성적→진단→목표→반영→정보 전 흐름을 실제 클릭·타이핑으로, 375·768·1280 × 라이트/다크 × 백분위·등급·표점, 공유 링크 복원, 시트 열기·완료·스크롤 보존, 375에서 시트를 연 채 1280으로 넓히면 시트가 사라지고 인라인 체크 행이 남는지(`widenRun`), 칩 뷰포트 안까지 단언한다.
