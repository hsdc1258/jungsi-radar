# 인계 — 판정 모델 v3 (환산점수 중심)

계약은 `docs/MODEL.md`, 화면 틀은 `docs/FRAME.md`(§10이 v3 표시 규약)다. 이 문서는 **지금 어디까지
왔고 무엇이 남았는가**만 적는다.

## 1. 완료

### 1.1 판정 층위 넷 (MODEL §3)
- 합격선 비교의 중심을 평균 백분위에서 **대학 환산점수**로 옮겼다. 모집단위마다 데이터가 허락하는
  가장 높은 층위 하나로 판정한다 — L1 환산 · L2 지수 · L3 참고 · L0 없음.
- 지금 분포(1,978곳 중): **L1 559 · L2 1,152 · L3 211 · L0 56**. 층위는 성적이 아니라 데이터가 정한다
  (산식 검산이 `verified`인가, 70% 학생의 영역별 백분위가 있는가) — 그래서 프로필이 달라도 분포가 같다.
- L1은 어디가 공시 환산점수 70%와 내 환산점수를 빼고, 산식의 국소 기울기로 백분위 상당을 만든다.
  L2는 같은 반영비율로 매긴 지수끼리 뺀다(FRAME §10.4). L3는 종전의 백분위 컷 비교다.

### 1.2 원자료
- **어디가 원값 직접 수집**(`source/adiga/`). 정시 값 2,019개 중 1,961개가 어디가 원값(A)이다.
  한 행 = 환산점수 50/70/80/90/100%와 그 지점 **학생 한 명**의 영역별 백분위·등급이다(MODEL §1.1).
- **2026 정시 요강 산식**(`source/rules-2026.base.json` + `part-a`·`part-b` → `npm run rules`가 합친다).
  43개 대학 209트랙. 확장 필드(분모·기본점수·가산 종류·상위 n 영역·형제 트랙)는 MODEL §1.2에 있다.
- **대학 공개 탐구 변환표준점수 17곳**(`source/conv-2026.json`). 나머지는 통합 근사표를 쓰고 화면·결과에
  `근사`로 남긴다.

### 1.3 산식 검산 (MODEL §1.4)
- `npm run verify` → `source/formula-check.json`. 어디가 70%·50% 학생을 되읽어 채점하고 공시 환산점수와
  ±1점 안에서 맞는지 본다. **verified 43 · mismatch 83 · unchecked 31 트랙**(대조한 행 3,927개).
- `verified` 트랙만 L1에 쓴다. 대학별 표는 `docs/AUDIT.md` §14이고 `npm run audit`가 그 절만 다시 쓴다
  (`scripts/formula-check-report.mjs`가 표시자 사이만 갈아 끼운다 — 다른 절은 손대지 않는다).

### 1.4 눈금 — 2026-09-11 정정
- **유리·불리(`areas[].contrib`)는 환산점수 점 단위다.** scale(×multiply ÷divide)·분모를 적용한
  `part.scaled`로 뺀다. 전에는 scale 앞 원점수로 빼서 국민대(÷200)에서 `탐구 −700.0`처럼 200배 부푼
  값이 나왔다. `tests/data.test.mjs`가 전 모집단위 × 프로필 셋으로 **|기여| ≤ 그 영역 배점**을 단언한다.
- **목표 화면 '필요한 상승'의 눈금도 층위가 정한다.** L1은 환산점수 점이고, 영역 비중은 산식의 국소
  기울기(그 영역 백분위 +1 → 환산점수 몇 점)다. 화면은 `국어 97.0 → 99.0 (+8.0점)`처럼 목표 백분위와
  점수를 함께 적는다. L2는 반영비율 비중, L3는 종전 1/3씩이다. 백분위→표준점수 되읽기가 성긴 자리
  (백분위 69와 70이 같은 표준점수)에서는 값이 움직일 때까지 폭을 넓히고 그 폭으로 나눈다.
- 목표 화면 `조건`의 옛 `반영비율 지수 … 컷과 눈금이 달라 차이를 내지 않음` 행은 **L3에서만** 남는다.
  L1·L2는 판정 눈금이 이미 환산점수·지수라 같은 이야기를 두 번 하지 않는다.
- 진단 '높은 순'의 2차 키는 컷의 **평균 백분위**(어디가 공시)다 — 환산점수·지수는 대학마다 눈금이 달라
  모집단위를 줄 세우는 데 쓰지 않는다(MODEL §5, FRAME §10.1).
- 반영점수 한 줄(`ratioText`)에서 영어 계수가 1인 대학은 등급 배점표의 1등급 값이 배점이다
  (숭실 `영200`, `영1`이 아니다). 탐구를 과목마다 더하고 네 영역 배점의 합이 총점과 맞으면 요강 표기대로
  `탐125+125`로 적는다. 요강이 `반영점수 …`를 적어 둔 트랙은 그 원문이 먼저다(국민대 `영100`).
- 등급 입력의 L1 판정 카드 부제는 가정값을 드러낸다:
  `2026 70% 897.0 · 내 환산 874.5 (850.1~895.0) · 가정 국3 수4 탐3·3`.

### 1.5 전형 분류 (MODEL §1.1-2 · FRAME §11)
- 어디가 전형명 177종을 **kind 아홉 가지**로 접고, 같은 모집단위·학년도의 **전 전형 행**을
  `jeongsi[year].types[]`에 싣는다(4,928행). 대표 행도 그 안에 있다.
- 엔진은 `evaluateJeongsi(..., { type })`·`diagnose(..., { type })`으로 그 전형 행을 판정 입력으로
  세운다. 기본 `general`은 대표 행과 같은 행이라 **옵션 없음 === `{type:'general'}`** 이다.
  그 전형 행이 한 해도 없으면 `status: 'no-type'`으로 목록에서 빠진다.
- 화면은 다섯 자리에서 그 전형을 따라간다: 진단 전형 칩·시트(단일 선택), 스탯 라벨
  `지원 가능 · 농어촌`, 목표 화면 전형 셀렉트(진단 선택이 기본), 근거 `지원` 행
  (`2027 · 수능(농어촌학생전형) · 다군`), 기준 숫자 표의 `전형` 열, 정보 탭 전형 분류 절.
  비교 입결·판정 숫자도 그 전형 행 값이다(숭실대 의생명시스템학부: 농어촌 지수 컷 87.6 /
  일반 88.9).
- 고를 수 있는 전형은 **컷이 공개된 kind만**이다 — 지금은 일반 1,942 · 농어촌 96 · 기회균형 58 ·
  지역인재 38 · 특성화고 33 · 실기·특기 2 · 기타 1곳.
- 특별전형은 일반 산식으로 재현하므로 결과에 `type-formula-assumed`(화면 `산식 가정` 뱃지)를
  단다. 뱃지 차례는 모의/추정 → 산식 가정 → 근사 → 판정이다.

### 1.6 화면·점검
- FRAME §8(애플 어법)·§9(필터 줄바꿈·바텀시트·실기/이상 뱃지)·§10(v3 근거 카드)·§11(전형)이 다 붙어 있다.

  시트·전형 시트·번들) · `npm run e2e`(폭 3종 × 2테마 × 입력 기준 3종 전 흐름 + 전형 6판) 모두 통과.
  전형 시나리오는 건너뛰지 않고 농어촌 흐름을 끝까지 돈다(`_shots/sheet-type.png`).

  모집인원 내역(`quotaDetail`)·환산점수 총점·80·90% 지점 학생은 빼고, 집계 방식은 어디가가
  공개한 행에만 적는다.
- 배포는 `main` 푸시 → GitHub Pages(https://hsdc1258.github.io/jungsi-radar/).
