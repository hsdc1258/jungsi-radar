# 판정 모델 v3 — 대학 환산점수 중심 (2026-09-11)

이 문서는 **계산 계약**이다. 엔진·빌드·화면은 이 계약대로 만들고, 어긋나면 이 문서가 이긴다.
사용자 판정(2026-09-11): "평균 백분위가 같으면 합격 가능성도 같다"는 가정을 없앤다. 합격선 비교의
중심은 **대학별 환산점수**이고, 평균 백분위는 보조 설명이다.

## 0. 확인된 사실 (원문)

- **어디가 정시 입결의 정의** (adiga.kr 대학별 입시결과 각주 원문):
  - "50% cut : 최종등록자 중 수능 환산점수 순으로 상위 50%에 해당하는 점수" (70%도 같은 방식)
  - "백분위 : 최종등록자 중 상위 50%, 70%에 해당하는 학생의 성적 산출에 반영된 수능 영역의 백분위"
  - "영어, 한국사 영역의 경우 등급"
  - "50%, 70% cut은 대학별 필수공개, 80%, 90%, 100% cut은 대학별 선택공개"
  - "모집 단위별 최종 선발 인원이 소수인 경우(선발인원 3명 이하)에는 공개하지 않음"
  - 즉 **환산점수 순으로 줄 세운 뒤 그 지점 학생 한 명**의 환산점수와 영역별 백분위·등급이다.
    "평균 백분위 순 70%컷"이 아니다. 영역별 값은 그 학생 한 명의 성적표다(평균백분위 = 그 학생의
    국·수·탐(2) 평균이 공시값과 일치하는지로 매 행 검산한다).
- **어디가 열 구조**(수능위주 입시결과): 모집시기 · 전형유형 · 전형명 · 학과명 · 모집인원(최초·이월·최종)
  · 경쟁률 · 충원인원 · 수능 환산점수 50/70/80/90/100% · 총점(수능) · 50%/70%/80%/90%/100% 각각의
  국어 · 수학 · 탐구1(사탐/과탐/직탐) · 탐구2(사탐/과탐/직탐) · 평균백분위 · 한국사(등급) · 영어(등급).
- **국민대 2026 정시 요강 p.53~54** (수능성적 반영식):
  `[Σ(반영영역 표준점수 × 반영점수) + (영어 배점 × 2 × 영어 반영점수)] × 최고점 ÷ (200 × 반영점수 합)`,
  탐구는 2과목 표준점수 **합**, 한국사는 총점에서 등급별 감점(1~4등급 0, 5등급 −0.2 … 9등급 −1.0),
  영어 배점 100/98/95/90/85/80/75/70/0. 자유전공(A) 국400·수300·영100·탐200(합 1,000, 최고점 1,000).
- **검산**: 어디가 2026 국민대 자유전공(A) 70% 지점 학생 = 국어 97 · 수학 69 · 사탐 86·52 · 영어 2 ·
  한국사 1, 평균백분위 78, 환산점수 659.0. 2026 수능 도수분포로 백분위→표준점수를 되읽으면
  국어 135~136 · 수학 116 · 사탐 62~63 / 52. 산식에 넣으면 **656.0~659.0**, 공시 659.0이 구간 안이다.
  같은 행의 50% 지점 학생은 국어 98 · 수학 76 · 사탐 62 · 과탐 77 · 영어 3, 평균 81, 환산 660.5 —
  평균 백분위는 3점 높은데 환산점수는 1.5점 차이다. 평균 백분위로는 이 둘을 가를 수 없다.
- 미래융합전공(C)(국500·영200·탐300, 수학 미반영)의 50%(평균 68) < 70%(평균 78)는 **모순이 아니다** —
  환산점수 순 정렬이라 국어가 강한 학생이 평균이 낮아도 위에 선다. 종전 이상치 규칙(50%컷 < 70%컷 = 오류)은
  틀렸으므로 폐기한다(§6).

## 1. 데이터 계층

### 1.1 입결 (`source/adiga/<학년도>.json`, 빌드가 `dept.jeongsi[year]`에 싣는다)
어디가 원문을 그대로 옮긴다. 한 행 = 대학 × 학년도 × 모집시기 × 전형 × 모집단위.
```
{ university, year, period: '정시(가)'|'정시(나)'|'정시(다)'|'추가', typeName, dept,
  quota: { initial, carried, final }, rate, fill,
  score: { p50, p70, p80, p90, p100, total },            // 수능 환산점수, 없으면 null
  student: { p50: {kor, math, inq1:{kind,pct}, inq2:{kind,pct}, avg, hist, eng}, p70: {...}, p80.. },
  aggregation: 'adiga-score-rank',                       // 집계 방식 — 어디가 각주 정의
  source: { title, url, fetchedOn }, sourceGrade: 'A' }  // 대학이 어디가에 제출한 공식값
```
- `student.pXX.avg`가 `(kor + math + (inq1+inq2)/2) / 3`(탐구 1과목이면 그 값)과 ±0.6 안에서 맞으면
  `consistent: true`. 아니면 `consistent: false`로 두고 그 행의 영역별 값을 **한 학생 성적표로 쓰지 않는다**
  (L2 판정 불가, L3만).
- 어디가가 아닌 출처(학점나비 전사, 기사 인용, 대학 자체 공개)는 `aggregation`을 원문이 말한 대로 적고,
  모르면 `'unknown'`이다. `unknown`이면 정밀 판정을 내리지 않는다(L3 참고만).
- 과거 학년도(2025·2024)도 같은 형식으로 싣는다. 학년도는 **입학 학년도**다(2026학년도 = 2025-11 수능).

### 1.2 산식 (`source/rules-<학년도>.json`)
대학 × 학년도 × 트랙(계열 또는 모집단위 지정). 2026은 **정시 모집요강** 원문, 2027은 **시행계획**
(요강 확정 전 — `status: 'plan'`).
```
{ id, name, year, status: 'final'|'plan',
  tracks: [{
    name, appliesTo: ['인문'|'자연'|'예체능'|'의약'|'자유전공'] | { depts: [...] }, groups: ['가','나'],
    areas: {
      kor:  { metric: 'std'|'pct', factor },
      math: { metric, factor, bonus: { electives: ['미적분','기하'], rate: 0.03 } },
      inq:  { metric: 'conv'|'std'|'pct', count: 1|2, aggregate: 'sum'|'mean', factor,
              bonus: { kind: 'science'|'social', rate } , conversion: 'official'|'approx'|'none' },
      eng:  { metric: 'table', table: {1..9}, factor },
      hist: { mode: 'penalty'|'table', table: {1..9}, factor }    // penalty는 scale 뒤 총점에서 뺀다
    },
    scale: { multiply, divide }, total, roundTo,
    optional: { pick: 'best', of: ['math','inq'] },                 // 조형대학처럼 상위 영역 택1
    eligibility: { requiredElectives, requiredInquiryKind },
    source: { title, url, page }, sourceGrade: 'A'|'B'|'C'|'D', note
  }] }
```
- 점수 = `(Σ area_value × factor) × multiply ÷ divide` − 한국사 감점, `roundTo` 자리 반올림.
  area_value: std = 표준점수(가산 rate 적용), conv = 변환표준점수(대학 표가 있으면 official, 없으면
  `conv-<year>.json`의 통합 근사표 approx — 근사임을 결과에 남긴다), pct = 백분위, table = 등급 배점.
- 국민대 자유전공(A) 2026 = `kor std 400 · math std 300 · inq std sum 200 · eng table ×200 · hist penalty`,
  `scale {multiply: 1000, divide: 200000}`, total 1000. (기존 `conv-2026.json`의 연세대 `formula`도
  이 형식으로 옮긴다.)
- 반영비율만 알고 산식·총점을 모르는 트랙은 `sourceGrade: 'B'`, `metric`을 비워 둔다 → L2까지만.
- **확장 필드**(2026 요강 원문이 기본 산식 하나로 안 담겨 등록자가 덧붙인 것. 없으면 기본 동작):
  - `areas.<area>.denominator` — factor를 곱하기 전에 영역값을 나누는 기준. `{kind:'maxStd', area, perSubject?, sumOfTwo?}` =
    그 해 전국 최고 표준점수(탐구는 perSubject면 과목별 최고점, sumOfTwo면 두 과목 최고점 합), `{kind:'maxConv', multiplier}` =
    변환표준점수 최고점 × n, `{kind:'const', value}`. 숙명·숭실·아주·인하·이화·외대·ERICA·경상국립 등.
  - `areas.<area>.base` — 그 영역의 기본점수(충북·한양).
  - `areas.<area>.bonus.of` — `'value'`(지표에 곱한 뒤 산식) · `'areaScore'`(그 영역 환산점수의 %) · `'pctToTotal'`(취득 백분위의 %를 총점에 가산,
    숭실). `per:'subject'`면 탐구 과목마다, `requireBoth`면 두 과목 모두 해당 종류일 때만.
  - `areas.eng.mode:'penalty'`(배점 없이 감점, 충남) · `areas.hist.mode:'none'`(미반영, 인천·충북·경상국립).
  - `pickBest: true` — 같은 모집단위에 걸리는 형제 트랙(인하 A/B, 항공 산출1·2, 이화 간호·약학) 중 높은 점수.
  - `optional {pick:'best'|'top2'|'rankedWeights', of:[…], weights?}` — 상위 n개 영역만 반영하거나 성적 순 가중.
  - `basePoints` · `formulaText` · `basis` — 기본점수 총점, 산식 원문 요약, 활용지표 요약(표시용).
  - 검산(§1.4)이 이 필드들을 실제로 소비하는지 보는 기준은 **어디가 환산점수 재현**이다. 재현이 안 되는 트랙은 `mismatch`로 남긴다.

### 1.3 척도
- `std-<학년도>.json`: 그 수능의 영역·과목별 표준점수 도수분포(백분위 포함). **백분위 → 표준점수**는
  이 표로만 되읽는다: 같은 백분위를 가진 표준점수의 집합(보통 1~2개)이 결과다. 탐구는 과목을 모르면
  같은 종류(사탐/과탐) 과목 전체에서 그 백분위를 가진 표준점수의 최소~최대. **표에 없는 조합은
  만들지 않는다** — 그 백분위에 해당하는 표준점수가 어느 과목에도 없으면 이웃 백분위의 표준점수로
  구간을 넓히고 `interpolated: true`를 남긴다.
- 사용자의 성적 학년도가 컷 학년도와 다르면(2027 지원자의 2026 입결 비교가 기본), **백분위 동등
  가정**으로 잇는다: 내 백분위를 컷 학년도 분포로 되읽은 표준점수를 쓴다. 이 가정은 결과의
  `assumptions`에 반드시 적힌다(`"2027 수능 백분위를 2026 수능 분포의 표준점수로 환산"`).

### 1.4 산식 검산 (`scripts/verify-formulas.mjs` → `source/formula-check.json`)
대학 × 학년도 × 트랙마다, 어디가 행의 70%(및 50%) 학생 영역별 백분위를 §1.3으로 표준점수 구간으로
되읽고 §1.2 산식에 넣어 환산점수 구간을 만든다. 어디가 환산점수가 **구간 ± 1.0점** 안이면 그 행은
`match`, 아니면 `mismatch`. 트랙의 판정:
- `verified`: 대조 가능한 행의 90% 이상 match (행이 3개 미만이면 전부 match)
- `mismatch`: 그 밖. **verified가 아닌 트랙은 L1 판정에 쓰지 않는다.**
- `unchecked`: 어디가 환산점수나 영역별 값이 없어 대조 불가.
결과는 정보 탭 '산식 검산' 표와 AUDIT에 실린다. 총점(`score.total`)이 산식 `total`과 다르면 mismatch다.

## 2. 내 점수

- 입력 기준 셋(백분위·등급·표준점수)은 그대로. 백분위·등급은 §1.3으로 컷 학년도 표준점수 **구간**이 된다.
  표준점수 입력은 그 학년도 분포에서 백분위를 읽고(현행), 컷 학년도가 다르면 다시 §1.3을 거친다.
- 모집단위마다 `score(track, profile)`:
  `{ value, min, max, parts: [{area, metric, input, factorApplied, points}], adjustments, assumptions,
     basis: 'formula', formulaYear, formulaStatus, conversion: 'official'|'approx'|null }`
  등급 입력은 등급 구간의 하한·중앙·상한 세 점을 다 계산한다(§4).
- 지원 자격(선택과목·탐구 종류)에 걸리면 `blocked`와 사유. 가산점은 조건이 맞을 때만.

## 3. 판정 — 네 층위

각 모집단위는 데이터가 허락하는 가장 높은 층위 하나로 판정하고, 층위 이름을 결과에 남긴다.

| 층위 | 조건 | 비교 | 단위 |
|---|---|---|---|
| **L1 환산** | 컷 학년도 산식 `verified` · 어디가 환산점수 70% 있음 · 내 점수 계산 가능 | 내 환산점수 − 어디가 환산점수 70% | 점 → 백분위 상당 |
| **L2 지수** | L1 불가이되 반영비율(A/B) 있음 · 70% 학생 영역별 백분위 `consistent` | 내 가중 지수 − 70% 학생의 가중 지수(같은 비율) | 백분위 |

- **L2 비율 조건**: 국어·수학·탐구 비율이 모두 0보다 커야 한다. 2027 시행계획 비율이 그렇지 않으면(서강·성균관·가톨릭처럼 표준점수 계수만 있는 곳) 컷 학년도 산식 트랙의 영역 계수(`areas.*.factor`, 영어는 배점표 1등급 값 × factor)를 비율로 쓰고, 그것도 없으면 L3다. 탐구 하나로만 매긴 지수는 판정이 아니다.
| **L3 참고** | 평균백분위(또는 국·수·탐 정의별 컷)만 있음 | 내 정의별 값 − 컷 | 백분위 |
| **L0 없음** | 집계 방식 `unknown` · 컷 없음 · 자격 미충족 | — | — |

- **L1의 단위 환산**: 점수 차를 백분위로 옮기려고 산식의 국소 기울기를 쓴다.
  `slope = score(내 영역 백분위 전부 +1) − score(내 성적)` (백분위 100 초과는 100에서 멈춤).
  `gapEq = gap / slope`. 화면은 점수 차와 백분위 상당을 둘 다 적는다.
- **2027 산식이 2026과 다를 때**(L1): 70% 학생의 영역별 성적을 2027 산식으로 다시 채점해 `cut2027`을
  만들고 내 2027 점수와 비교한다(둘 다 같은 산식·같은 분포). 2026 산식 기준 차이도 함께 돌려주고, 두
  판정이 다르면 `basisChanged: true`로 화면이 둘 다 적는다. 2027 산식이 `plan`이면 그 사실을 적는다.
- **띠**(gapEq, 백분위 상당): 안정 ≥ +2.0 · 적정 ≥ +0.7 · 소신 ≥ −0.7 · 상향 ≥ −2.0 · 위험 < −2.0.
  단 **안정은 50% 지점도 넘어야 한다**: 50% 환산점수가 있고 내 점수가 그 아래면 적정으로 내린다.
  70%컷은 보장선이 아니다 — 띠 이름 옆에 "70% 지점 대비"를 반드시 붙인다.
- 층위마다 **불확실성 폭**을 붙인다: L1 = 내 점수 구간 폭 + 변환표 근사(approx면 ±0.5점 상당) +
  학년도 차이(백분위 동등 가정) · L2 = ±1.0 + 지수 근사 · L3 = ±2.0(과목 조합을 모른다). 화면은
  `참고 판정 · 불확실성 ±n` 형태다. 합격 확률 숫자는 어디에도 만들지 않는다.
- **유리·불리 과목**(L1·L2): 영역별 기여 `contrib[area] = (내 area 점수 − 70% 학생 area 점수)`를
  점수 단위로 낸다. 절댓값 큰 순으로 두 개까지 화면에 `국어 +6.2 · 수학 −9.0`처럼 적는다. 평균 백분위
  차이(`avgGap`)와 환산 차이(`gapEq`)의 부호나 크기가 다르면 그 자체가 설명이다:
  `평균 백분위로는 +0.3인데 이 대학 산식으로는 −1.9 (수학 300점)`.

## 4. 등급 입력

- 등급 → 백분위 구간(제도가 정한 경계) → §1.3으로 표준점수 구간. 하단·중앙·상단 세 점을 다 계산한다.
- 판정은 중앙값 하나로 내되 `추정` 뱃지, 하단·상단 판정을 함께 돌려준다(현행 유지).
- **민감도**: 반영 배점이 가장 큰 영역 하나에 대해 "그 등급 안에서 하단→상단이면 환산점수 +n점(백분위
  상당 +m)"을 낸다. 화면은 값만 한 줄.
- 모의고사·목표 성적은 실제 수능이 아니다. 입력 화면의 성적 출처(`sourceKind: 'actual'|'mock'|'target'`)를
  받아 결과에 `추정` 대신 `모의`·`목표` 뱃지를 붙인다. 기본값은 `mock`(수능 전)이다.

## 5. 학년도와 비교 가능성

- 결과 문구는 항상 `2027 지원 · 2026 입결 기준`처럼 **두 학년도**를 적는다. "작년"이라 쓰지 않는다.
- 같은 모집단위의 연속 비교는 이름이 아니라 **선발 조건**이 같을 때만: 모집군·모집인원·반영비율·가산이
  바뀌었으면 `series`에서 끊고 `changed: ['모집군 가→나', '반영비율']`로 남긴다. 신설·통합·분리는
  `lineage`로 적고 이어 붙이지 않는다.
- 다른 대학·다른 산식의 환산점수는 숫자로 비교하지 않는다(화면에서 두 대학의 환산점수를 나란히 두지
  않는다). 같은 대학의 전년도 환산점수도 산식이 바뀌었거나 분포 보정 근거가 없으면 `전년도 참고 비교`로만.

## 6. 펑크·오류

- **오류 의심**: 환산점수 50% < 70%(같은 정렬에서 불가능), 총점 초과, 백분위 범위 밖, 평균백분위가
  영역별 값과 불일치(§1.1 consistent=false는 오류가 아니라 '영역별 값 사용 불가').
- **펑크 의심**: 같은 선발 조건(§5)에서 환산점수 70%(또는 평균백분위)가 전년보다 문턱 이상 낮고, 경쟁률
  하락·충원 ≥ 모집인원 중 하나 이상이 함께 있을 때. 백분위 하나만으로 부르지 않는다.
- 그 밖은 **판단 불가**로 남긴다(뱃지 없음).
