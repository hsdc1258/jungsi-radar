# 정시 레이더

수능 백분위(또는 등급)를 넣으면 수도권 주요 29개 대학 정시 지원선과 얼마나 떨어져 있는지 보여 주는
정적 웹사이트입니다. 서버도 빌드 도구도 없이 `index.html` 하나와 `assets/*.js` 세 개로 돕니다.

- **성적** — 국어·수학 선택과목, 탐구 2과목, 영어·한국사 등급, 내신(선택). localStorage에 자동 저장되고
  `?k=96&m=93…` 쿼리로 성적 링크를 만들어 공유할 수 있습니다. 등급으로 넣으면 **그 등급 구간의 정확한
  중앙값**(1등급 98.0 · 2등급 92.5 · 3등급 83.0 · 4등급 68.5 · 5등급 50.0 · 6등급 31.5 · 7등급 17.0 ·
  8등급 7.5 · 9등급 2.0)으로 환산하고, "2등급 → 92.5(구간 중앙)"처럼 무엇으로 바뀌었는지 화면에 적습니다.
- **진단** — 대학별 반영 방법을 적용한 내 환산 백분위와 예상 컷의 차이를 판정(안정·적정·소신·상향·위험)으로 보여 줍니다.
  기본 정렬은 **예상 컷 높은 순**(갈 수 있는 가장 높은 곳부터)이고, 지원 가능(안정·적정·소신)을 먼저,
  상향·위험·불가를 그 아래에 잇습니다. 정렬 셀렉트로 판정별 묶음 보기로 바꿀 수 있습니다.
  칩 줄의 **예체능 제외**·**말도 안되는거 제외** 토글은 기본으로 켜져 있어 실기 학과와
  의·치·한·약·수의 및 서울대·연세대·고려대를 목록에서 감춥니다(관심 학과와 공유 링크로 연 곳은 그대로 보입니다).
- **목표** — 한 모집단위를 골라 필요한 상승폭, 영역별 1점의 효과, 영어 등급 상승 효과, 연도별 컷·경쟁률·충원을 봅니다.
  관심 학과를 저장하면 같은 성적으로 나란히 비교합니다.
- **반영** — 대학별 2027학년도 정시 수능 반영 방법(비율·영어·한국사·탐구 가산)과 2026학년도 수능 선택과목 원점수 컷.
- **정보** — 판정 기준, 출처, 아직 확인하지 못한 규칙 목록.

## 데이터 출처

| 무엇 | 출처 | 비고 |
|---|---|---|
| 2026학년도 정시 최종등록자 70% 컷 | 대입정보포털 어디가 공개값(학점나비 집계 페이지 경유) | 국·수·탐(2) 백분위 평균 |
| 2024·2025학년도 정시 결과 | 각 대학이 낸 입시결과 자료(단국·광운·숭실·경희·동국·성균관·삼육·명지) | 값의 종류(70%컷·평균·80%평균)를 `kind`로 남깁니다 |
| 2026학년도 가천대 정시 결과 | 베리타스알파가 옮긴 가천대 공식 입결(일반전형1 국·수·탐 백분위 70%컷 20개 모집단위) | 어디가·학점나비에 가천대 정시 백분위 표가 없어 이 값을 씁니다 |
| 2027학년도 정시 수능 반영 방법 | 각 대학 2027학년도 대학입학전형 시행계획 | 영역별 비율, 영어·한국사 환산, 선택과목 가산 |
| 2026학년도 수능 등급컷 | 교육부·한국교육과정평가원 채점 결과(2025-12-05 확정) | 국어·수학 선택과목별, 탐구 17과목 |

### 값을 섞지 않는 방법

대학이 스스로 내는 값은 정의가 제각각입니다(등록자 평균, 상위 80% 평균, 70%컷…). 그래서 **수준을 그대로
어디가 70%컷과 섞지 않습니다.** 대신 같은 학과의 **연도 사이 변화량**만 빌려, 기준 연도(어디가 값이 있는 해)의
컷에서 평행이동시킵니다. 그렇게 만든 값은 `basis: 'derived'`로 표시되고 화면에도 그렇게 적힙니다.

### 대학 순서

대학은 라인(서연고·서성한…) 순이 아니라 **대표 컷 내림차순**입니다. 대표 컷은 예체능·의약을 뺀 일반
모집단위의 2026학년도 정시 70%컷 백분위 **중앙값**이고, 라인 이름은 참고 라벨로만 남습니다. 진단 목록의
동점 정렬, 목표 탭 대학 셀렉트, 정보 탭의 대학 목록이 모두 이 순서를 따릅니다.

판정의 기준값은 이렇게 모은 연도별 값의 **최근 가중 평균(0.6 / 0.3 / 0.1)** 이고,
오차는 **연도별 최소~최대 폭의 절반**입니다. 값이 한 해뿐이면 같은 대학 다른 학과들의 연도별
표준편차 중앙값을 오차로 씁니다.

## 갱신 방법

소스는 `source/` 아래 JSON 세 개뿐입니다. 생성물(`assets/data.js`)은 손으로 고치지 않습니다.

```
source/results.json      # 대학·모집단위별 연도별 정시·수시 결과
source/rules-2027.json   # 2027학년도 정시 수능 반영 방법
source/scales-2026.json  # 수능 등급컷 기준표

npm run build   # source/*.json → assets/data.js
npm test        # 엔진·데이터 불변식·렌더러 스모크 (node --test, 의존성 없음)
```

브라우저 확인(Playwright가 있는 환경에서):

```
npm run bundle  # dist/jungsi-radar.html — 한 파일짜리 사본(어디에나 붙여 넣는 조각)
npm run check   # 320·375·414·768·1024·1280 × 라이트/다크 × 다섯 탭 + 번들 두 판을 실제로 열어
                # 가로 넘침·고정바 겹침·잘린 텍스트·콘솔 오류·실패한 요청이 있으면 실패로 끝난다
                # (스크린샷은 _shots/ 에 남는다)
```

## 배포

`main`에 밀면 `.github/workflows/pages.yml`이 테스트를 돌리고 GitHub Pages로 올립니다.
**저장소에서 Pages를 한 번 켜 두어야 합니다** — Settings → Pages → Source를 `GitHub Actions`로.
켜기 전에는 배포 작업이 `Create Pages site failed. Resource not accessible by integration`으로
멈춥니다(워크플로의 토큰에는 Pages를 새로 만들 권한이 없습니다).

## 한계

- **환산점수만 공개된 모집단위는 판정하지 않습니다.** 표준점수 기반 환산을 백분위로 되돌리면
  오차가 커서 숫자를 지어내는 셈이 됩니다.
- **탐구 변환표준점수 표는 대학이 공개하지 않아** 가산 규칙(과탐/사탐 가산 몇 %)으로만 반영합니다.
- 시행계획 원문에서 값을 찾지 못한 규칙(성균관대 영어 자체 변환표, 건국대·국민대 일부 표 등)은
  비워 두었고, 정보 탭의 "아직 확인하지 못한 규칙" 목록이 자동으로 그 수를 셉니다.
- 모집단위가 개편된 해는 이름이 이어지지 않아 연도별 값을 묶지 못한 경우가 있습니다.
- **여자대학교(이화여대·숙명여대)는 다루지 않습니다.** 원자료는 `source/`에 남아 있지만 생성물에는 넣지 않습니다.
- **가천대는 20개 모집단위만** 공개 백분위가 있어 대표 컷이 실제보다 높게 잡힙니다(상위 20위 목록이라서).
- **합격을 보장하지 않습니다.** 실제 지원은 각 대학 모집요강을 확인하세요.

## 구조

```
index.html          골격(상단바·탭·패널·푸터). 테마 복원 스크립트만 인라인입니다.
assets/frame.css    배치와 간격만. 색·컴포넌트 모양은 Seed Design(@seed-design/css@2.7.0)이 맡습니다.
assets/data.js      생성물
assets/engine.js    순수 계산 (globalThis.IPSI_ENGINE) — 화면과 테스트가 같은 파일을 씁니다
assets/app.js       화면
docs/FRAME.md       화면 틀. 여기 없는 패턴은 만들지 않습니다.
```

배포는 `main`에 push하면 GitHub Actions가 테스트를 돌린 뒤 GitHub Pages로 올립니다.
